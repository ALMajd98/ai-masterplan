المرحلة 1 — التأسيس

تجهيز بيئة العمل

قبل بناء منظومة قوية، لازم نبدأ من قاعدة نظيفة. هذي المرحلة الأهم لأنها تحدد استقرار وأداء كل شي يجي بعدها.

قبل أن تبدأ

الفورمات سيمسح كل شيء على جهازك. تأكد من عمل نسخة احتياطية لكل ملفاتك المهمة.

01

تثبيت Chocolatey (مدير الحزم)

3 دقائق

Chocolatey يخليك تثبت أي برنامج بأمر واحد بدل التصفح والتحميل يدوياً.

PowerShell (Administrator) 
Set-ExecutionPolicy Bypass -Scope Process -Force
[System.Net.ServicePointManager]::SecurityProtocol = 3072
iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
02

إعداد Git

دقيقتان
PowerShell 
# تثبيت Git
choco install -y git

# إعداد Git (استبدل بمعلوماتك)
git config --global user.name "The_Majd"
git config --global user.email "malyafi2@gmail.com"
git config --global init.defaultBranch "main"
git config --global core.autocrlf true
03

Node.js 22 LTS + Bun + أدوات التطوير

10 دقائق
PowerShell (Admin) 
# تثبيت كل الأدوات دفعة واحدة
choco install -y nodejs-lts python vscode docker-desktop `
  windows-terminal powershell-core 7zip notepadplusplus `
  postman github-desktop googlechrome brave firefox vlc

# تثبيت Bun (محرك JS فائق السرعة)
powershell -c "irm bun.sh/install.ps1 | iex"

# تثبيت الحزم العالمية
npm install -g typescript ts-node nodemon pm2 pnpm yarn --force
04

Python 3.12 + مكتبات AI

5 دقائق

مشكلة Python الشائعة في ويندوز 11

إذا ظهر "Python was not found" عطّل: Settings → Apps → Advanced app settings → App execution aliases ⬅️ أوقف python.exe و python3.exe

PowerShell 
# تحديث pip
python -m pip install --upgrade pip

# تثبيت مكتبات AI الأساسية
pip install jupyter pandas numpy matplotlib requests `
  beautifulsoup4 python-dotenv fastapi uvicorn `
  openai anthropic ollama langchain langgraph `
  chromadb qdrant-client sentence-transformers
05

WSL2 + Ubuntu 24.04

15 دقيقة
PowerShell (Admin) 
wsl --install
wsl --set-default-version 2

# بعد إعادة التشغيل:
wsl --install -d Ubuntu-24.04
06

إنشاء مجلدات المشروع على القرص D

دقيقة واحدة
PowerShell 
# المجلد الرئيسي للمشاريع على القرص D
New-Item -ItemType Directory -Force -Path "D:\Projects"

# مجلد المنظومة الشاملة
New-Item -ItemType Directory -Force -Path "D:\Projects\AI-Workspace\skills"
New-Item -ItemType Directory -Force -Path "D:\Projects\AI-Workspace\modes"
New-Item -ItemType Directory -Force -Path "D:\Projects\AI-Workspace\mcps"
New-Item -ItemType Directory -Force -Path "D:\Projects\AI-Workspace\docs"

# فتح المشروع بـ VS Code
code D:\Projects\AI-Workspace

لماذا القرص D؟

فصل المشاريع عن قرص النظام C يحمي بياناتك عند إعادة تنصيب Windows ويسرّع الوصول للملفات الكبيرة.
