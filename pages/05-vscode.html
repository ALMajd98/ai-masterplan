03

إنشاء مجلد .clinerules (الدستور)

5 دقائق
PowerShell 
# إنشاء بنية مجلدات Cline في مشروعك
cd D:\Projects\AI-Workspace
mkdir .clinerules
mkdir .clinerules\modes
mkdir .clinerules\standards
mkdir .clinerules\skills
mkdir .clinerules\templates

# فتح المشروع بـ VS Code
code D:\Projects\AI-Workspace

ما هو .clinerules؟

مجلد قواعد مخصصة. كل مرة تفتح المشروع، Cline يقرأ هذه القواعد تلقائياً ويلتزم بها. سنملأه بالدستور في الصفحات القادمة.
