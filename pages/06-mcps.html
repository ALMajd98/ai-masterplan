Model Context Protocol

المعيار الصناعي الموحّد

MCP: USB للـ AI

Model Context Protocol هو المعيار المسيطر عالمياً. تحت رعاية Linux Foundation منذ ديسمبر 2025، مع أكثر من 10,000 خادم MCP نشط.

ما هو MCP بالضبط؟ المفهوم

"USB للذكاء الاصطناعي"

بروتوكول موحّد يخلي أي AI يتصل بأي أداة خارجية بنفس الطريقة. لا تحتاج كود مخصص لكل أداة.

Linux Foundation (AAIF)

معيار محايد لا تملكه شركة واحدة. يدعمه: Anthropic, Google, Microsoft, Cursor, VS Code, Cline.

10,000+ خادم نشط

من ملفات محلية إلى قواعد بيانات إلى متاجر إلكترونية. كل شي له MCP.

سجلات MCP الرسمية 4 سجلات

السجل عدد الخوادم الميزة الرابط
Glama 22,775+ الأكبر — بيانات تفصيلية + sandbox glama.ai
Smithery 7,000+ مثل Docker Hub — تثبيت سريع smithery.ai
MCP.so الرسمي التحقق من المصدر (DNS verification) mcp.so
PulseMCP 4,500+ مفهرس من npm / PyPI pulsemcp.com

إعداد MCP في Cline ملف واحد

افتح Cline → Settings (الترس) → MCP Servers → Add Server. أو عدّل الملف مباشرة:

cline_mcp_settings.json 
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "@modelcontextprotocol/server-filesystem",
        "D:\\Projects"
      ]
    },
    "github": {
      "command": "npx",
      "args": ["@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_TOKEN": "ghp_YOUR_TOKEN"
      }
    },
    "brave-search": {
      "command": "npx",
      "args": ["@modelcontextprotocol/server-brave-search"],
      "env": {
        "BRAVE_API_KEY": "BSA_YOUR_KEY"
      }
    },
    "sqlite": {
      "command": "npx",
      "args": [
        "@modelcontextprotocol/server-sqlite",
        "D:\\Projects\\db.sqlite"
      ]
    }
  }
}
