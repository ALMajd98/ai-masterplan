Multi-Agent Systems

المحركات متعددة العملاء (Multi-Agent)

محركات الأتمتة المتقدمة

تنتقل أنظمة الـ Multi-Agent بالذكاء الاصطناعي من مستوى "المحادثة الفردية" إلى مستوى فرق العمل البرمجية المتوازية. يقوم كل عميل (Agent) بتنفيذ مهمة مخصصة كالبحث أو مراجعة الأخطاء أو رفع الكود والتعاون التلقائي للوصول للهدف.

أقوى الأطر البرمجية لأنظمة الـ Multi-Agent (سبتمبر 2026) بيئة بايثون و جافا سكربت

الإطار البرمجي اللغة نمط البناء (Architecture) الاستخدام الأمثل
CrewAI Python إدارة تعاقبية وتقسيم مهام مباشر (Role-playing) أبحاث السوق المتقدمة وصناعة المحتوى الآلي
LangGraph Python / TS Graphs معقدة تدعم الحلقات الدائرية (Cyclic Graphs) بناء بيئات التطوير الصارمة ذات التقييم المستمر
Mastra TypeScript بناء بيئات تسلسلية مرنة وخفيفة للـ Node/Bun تطبيقات الويب السحابية ومصممي جافا سكربت

قالب بايثون متكامل لبناء فريق عمل ذكي عبر CrewAI و Ollama محلياً شفرة جاهزة للتنفيذ

هذا السكربت يربط نموذج qwen3.6:35b-a3b المحلي في جهازك ليعمل كمحرك لعميلين (باحث ومحلل مالي) يتعاونان آلياً:

crew_local_engine.py 
from crewai import Agent, Task, Crew, Process
from langchain_community.llms import Ollama

# 1. تعريف المحرك المحلي (Ollama) باستخدام أقوى نموذج برمجي لجهازك
local_llm = Ollama(model="qwen3.6:35b-a3b")

# 2. إنشاء عميل أبحاث السوق المستهدف
research_agent = Agent(
    role="محلل سوق سعودي خبير",
    goal="البحث والتقصي عن المنتجات الأكثر طلباً في الرياض وجدة لعام 2026",
    backstory="أنت باحث تسويقي متمكن، تمتلك نظرة ثاقبة لترندات المستهلكين في الخليج والمنصات المحلية مثل سلة وزد.",
    verbose=True,
    allow_delegation=False,
    llm=local_llm
)

# 3. إنشاء عميل صياغة خطة العمل وحساب الهوامش الربحية
business_analyst = Agent(
    role="مستشار مالي وإداري",
    goal="صياغة خطة تسعير دقيقة وحساب هوامش الأرباح الشاملة معVAT 15%",
    backstory="مستشار مالي متخصص في التجارة الإلكترونية وسلاسل الإمداد، بارع في حساب تكاليف الشحن والتسويق الرقمي لتفادي الخسائر.",
    verbose=True,
    allow_delegation=True,
    llm=local_llm
)

# 4. صياغة المهام وتحديد المسؤوليات
task_research = Task(
    description="قم بإعداد قائمة تضم 3 فئات من المنتجات الرابحة في السعودية مع تحليل نقاط القوة والضعف للمنافسين.",
    expected_output="تقرير أبحاث سوق مفصل بملف Markdown.",
    agent=research_agent
)

task_financial = Task(
    description="بناءً على تقرير البحث، صمم نموذج تسعير افتراضي يوضح سعر التكلفة، الشحن، التغليف، والربح الصافي بالريال السعودي.",
    expected_output="جدول تسعير مالي واضح مع توصيات إدارية.",
    agent=business_analyst
)

# 5. تكوين وإطلاق مسار العمل (Sequential Process)
local_crew = Crew(
    agents=[research_agent, business_analyst],
    tasks=[task_research, task_financial],
    process=Process.sequential,
    verbose=True
)

Write-Host = local_crew.kickoff()
print("### ناتج عمل المنظومة المستقلة:")
print(Write-Host)
