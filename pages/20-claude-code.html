Claude Code

أداة سطر الأوامر (CLI) الرسمية من Anthropic، تستخدم نماذج Claude Opus 4 & Sonnet 4.5 — أذكى نماذج AI في العالم. مثالية للمهام المعقدة والمراجعات الاحترافية، تتكامل بسلاسة مع Cline لتشكيل منظومة متكاملة.

نماذج Claude Opus 4 و Sonnet 4.5 هي الأقوى في العالم للبرمجة المعقدة والمراجعات العميقة.

01

تثبيت Claude Code CLI

5 دقائق

Claude Code يعمل كأداة سطر أوامر مستقلة. التثبيت عبر npm (الطريقة الرسمية والأسهل):

PowerShell (Administrator) 
# تثبيت Claude Code عالمياً عبر npm
npm install -g @anthropic-ai/claude-code

# التحقق من التثبيت
claude --version

# أو تحقق من مكان التثبيت
where claude

متطلبات التثبيت

Node.js 18+ (موجود عندك)، npm 9+ (موجود عندك). التثبيت سريع لا يحتاج أي إعدادات إضافية.

02

ربط Claude Code مع OpenRouter (الطريقة الذكية)

3 دقائق

الفكرة الذكية

بدل الاشتراك المباشر مع Anthropic ($20+/شهر)، استخدم OpenRouter كجسر — نفس القوة بتكلفة أقل!

أضف هذين المتغيرين في PowerShell (أو احفظهم بشكل دائم في System Variables):

PowerShell 
# للجلسة الحالية فقط
$env:ANTHROPIC_BASE_URL = "https://openrouter.ai/api/v1"
$env:ANTHROPIC_API_KEY = "sk-or-v1-YOUR_OPENROUTER_KEY"

# للحفظ الدائم (موصى به)
[System.Environment]::SetEnvironmentVariable('ANTHROPIC_BASE_URL', 'https://openrouter.ai/api/v1', 'User')
[System.Environment]::SetEnvironmentVariable('ANTHROPIC_API_KEY', 'sk-or-v1-YOUR_KEY', 'User')

# التحقق
echo $env:ANTHROPIC_BASE_URL
echo $env:ANTHROPIC_API_KEY

البديل: الاشتراك المباشر مع Anthropic اختياري

الطريقة الرسمية console.anthropic.com تحتاج بطاقة ائتمان دولية
الحد الأدنى $5 رصيد يكفي لأسبوعين
الميزة Priority Access أولوية في الاستجابة

متى تختار الاشتراك المباشر؟

إذا كنت تستخدم Claude Code بشكل مكثف يومياً (6+ ساعات)، الاشتراك المباشر يصبح أرخص. للمستخدم العادي، OpenRouter أفضل.

الأوامر الأساسية في Claude Code جاهزة

Claude Code Commands 
# === أوامر داخل Claude Code ===

/help              # عرض كل الأوامر
/model             # تغيير النموذج (opus-4, sonnet-4.5)
/clear             # مسح المحادثة
/reset             # إعادة التهيئة الكاملة
/exit              # الخروج

# === استخدامات شائعة ===

claude "اشرح لي ملف server.ts"
claude "ابحث عن bugs في المشروع"
claude "اكتب tests للـ API endpoints"
claude "راجع الـ security في login.ts"
claude "حسّن الأداء في database queries"

# === مع ملفات محددة ===
claude --file server.ts "راجع هذا الملف"
claude --dir src/api "راجع كل الـ APIs"
