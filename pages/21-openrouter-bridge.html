الحصول على مفتاح OpenRouter

3 دقائق

الخطوات

  1. افتح: openrouter.ai/keys
  2. سجّل بحساب Google أو GitHub (أسرع طريقة)
  3. اضغط "Create Key"
  4. اختر اسماً للمفتاح (مثلاً: "AI Master Plan")
  5. انسخ المفتاح (يبدأ بـ sk-or-v1-...)
  6. (اختياري): أودع $10 لرفع الحدود إلى 1000 طلب/يوم
02

ربط OpenRouter مع الأدوات

5 دقائق

مع Cline:

  1. افتح Cline في VS Code
  2. اضغط Settings (الترس)
  3. اختر Provider: OpenRouter
  4. ألصق المفتاح
  5. اختر Model (مثلاً: anthropic/claude-sonnet-4.5)

مع Claude Code:

PowerShell 
# حفظ دائم في متغيرات النظام
[System.Environment]::SetEnvironmentVariable(
    'ANTHROPIC_BASE_URL',
    'https://openrouter.ai/api/v1',
    'User'
)
[System.Environment]::SetEnvironmentVariable(
    'ANTHROPIC_API_KEY',
    'sk-or-v1-YOUR_KEY_HERE',
    'User'
)

# التحقق
echo $env:ANTHROPIC_BASE_URL
echo $env:ANTHROPIC_API_KEY
